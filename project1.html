Hill Cipher Text Encryption

Description

This project encrypts alphabetic characters from a plaintext file using the Hill cipher algorithm. A key is provided as an n by n matrix (between 2 by 2 and 9 by 9), and the program processes the text by cleaning and padding with 'x' before encryption. The ciphertext is displayed in uppercase directly to the console.

  • Encrypts text using the Hill cipher with a matrix size of 2 by 2 up to 9 by 9.
  • Cleans input by converting to lowercase, removing non-alphabetic characters, and padding with 'x'.
  • Reads matrix and plaintext from files, then applies matrix multiplication and mod 26 arithmetic.
  • Outputs key matrix, formatted plaintext, and resulting ciphertext (80 characters per line).

Skills Learned

  • Matrix operations and modular arithmetic.
  • String manipulation and data cleaning.
  • Working with a remote Unix server (Eustis) via SSH and Bash commands.
  • Debugging and compiling with GCC in a Unix environment.
