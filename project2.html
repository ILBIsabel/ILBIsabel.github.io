Checksum Calculator

Description

This project is a C program that calculates the checksum of a text file using 8-bit, 16-bit, or 32-bit checksums. The program processes the file by formatting its content, applying padding as needed, and computing the checksum value. The output includes the formatted text, calculated checksum in hexadecimal, and total character count.

  • Supports checksum sizes of 8, 16, or 32 bits.
  • Formats input text into 80-character lines with proper padding. Pads incomplete blocks with 'X'.
  • Includes newline characters in the checksum computation.
  • Detects invalid checksum sizes and handles errors gracefully.
  • Outputs both the processed file content and the final checksum result.

Skills Learned

  • File handling and memory allocation.
  • File I/O and buffer management.
  • Understanding and implementing checksum algorithms.
  • Bitwise operations and modulo arithmetic.
  • Text formatting and character processing.
  • Using GCC for compilation and testing with provided Bash scripts.
